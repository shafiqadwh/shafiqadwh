# ตัวแทน Android สำหรับเทสต์ `SlideshowActivity`

ไฟล์ในโฟลเดอร์นี้ **ไม่ใช่โค้ดของแอป** และไม่ได้ถูกใส่ลงใน APK — เป็นคลาสปลอม
ที่ทำหน้าที่แทนของจริงของ Android แค่พอให้ `javac` คอมไพล์
`tv/app/src/main/java/.../SlideshowActivity.java` **ตัวจริง** ได้ แล้วเรียก
callback ของ `WebViewClient` ใส่มันเหมือนที่ WebView ของจริงเรียก

ทำแบบนี้เพราะจอทีวีไม่มีทางเปิด DevTools ดูได้ และเครื่องที่รันเทสต์ไม่มี Android SDK
ให้รันอีมูเลเตอร์ — ถ้าไม่มีตัวแทนพวกนี้ เทสต์จะทำได้แค่ grep หาข้อความในซอร์ส
ซึ่งผ่านได้ทั้งที่แอปพัง

**จุดที่ต้องเหมือนของจริงเป๊ะ ๆ มีข้อเดียว**: WebView เรียก `onPageFinished`
สำหรับหน้า error ของตัวเองด้วย — ตัวขับใน `test/tv-app.test.js` จึงยิง
`onReceivedError` แล้วตามด้วย `onPageFinished` เสมอ นั่นคือกับดักที่ทำให้แอป
ติดแหง็กอยู่กับไอพีในวง LAN ตอนทีวีต่อ 5G
