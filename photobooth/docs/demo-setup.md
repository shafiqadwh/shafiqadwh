# ตั้งบูธเดโม ด้วยของที่มีอยู่แล้ว

เว็บแคม + Epson อิงค์เจ็ท + กระดาษ A4 · **ไม่ต้องซื้อ dye-sub และไม่ต้องซื้อกล้อง**

ได้ของที่มีขนาดเท่าสินค้าจริง (4×6 นิ้ว) พร้อมเส้นตัด — เอาไปเสนอลูกค้าได้เลย
ต่างจากของจริงแค่ต้องตัดเองกับคุณภาพหมึก ซึ่งเป็นสองอย่างที่เครื่อง dye-sub แก้ให้ทีหลัง

---

## 1. ระบบปฏิบัติการ — Ubuntu 24.04 LTS Desktop

เหตุผลที่เลือกตัวนี้กับบอร์ด Celeron G + RAM 8 GB

| | |
|---|---|
| **CUPS ติดมาในตัว** | โหมดพิมพ์ `cups` ของโปรแกรมใช้ได้ทันที ไม่ต้องลงอะไรเพิ่ม |
| **ไดรเวอร์ Epson อยู่ในคลังแพ็กเกจ** | `printer-driver-escpr` ครอบ L-series กับ inkjet ส่วนใหญ่ · ไม่ต้องไปหาไฟล์จากเว็บผู้ผลิต |
| **ไม่มีอัปเดตบังคับรีสตาร์ต** | ความเสี่ยงจริงของ Windows คือเครื่องรีสตาร์ตกลางงานที่แขกต่อแถวอยู่ |
| **ไม่มีค่าลิขสิทธิ์** | ต้นทุนต่อบูธหนึ่งตัวลดลงตรง ๆ ถ้าขยายเป็นหลายตัว |
| RAM 8 GB เหลือเฟือ | ตัวโปรแกรมใช้ราว 400–600 MB ตอนประกอบแผ่น |

> เลือก **Ubuntu Desktop** ไม่ใช่ Server — ต้องมีหน้าจอกราฟิกให้ Electron เปิดหน้าต่าง

## 3. ต่อเครื่องพิมพ์ แล้วหาชื่อของมัน

เสียบสาย USB แล้ว Ubuntu มักเจอเองใน **Settings → Printers** · จากนั้น

```sh
lpstat -p -d
```

จะได้บรรทัดหน้าตาแบบ `printer EPSON_L3210_Series is idle.`
**ชื่อที่ต้องเอาไปใส่ในค่าตั้งคือ `EPSON_L3210_Series`** (ตัวที่อยู่หลังคำว่า printer)

ตรวจว่ามันรับ A4 จริง

```sh
lpoptions -p EPSON_L3210_Series -l | grep -i pagesize
```

ต้องเห็น `A4` อยู่ในรายการ · ถ้าใช้กระดาษรูป 10×15 ซม. ให้มองหา `4x6` หรือ `Postcard`

## 5. ตั้งค่าสำหรับเดโม

สร้างไฟล์ `~/.config/photobooth/booth/settings.json`

```json
{
  "eventTitle": "ชื่องานของลูกค้า",
  "eventSubtitle": "29 สิงหาคม 2569 · สถานที่",
  "theme": "wedding",
  "template": "strip",
  "paper": "4x6",
  "printPage": "A4",
  "copies": 2,
  "effects": ["clean", "soft", "film"],
  "countdownSeconds": 3,
  "qrMode": "off",
  "printer": { "driver": "cups", "name": "EPSON_L3210_Series" }
}
```

**สามค่าที่สำคัญที่สุดสำหรับเดโม**

- `"printPage": "A4"` — แผ่นขนาดสินค้าจะไปนั่งกลางหน้า A4 พร้อมเส้นตัดที่มุม
  **ขนาดที่พิมพ์ออกมาเท่าสินค้าจริงเป๊ะ ไม่ถูกย่อ** (โปรแกรมสั่ง `scaling=100` ไม่ใช่ fit-to-page)
- `"copies": 2` — A4 หนึ่งแผ่นใส่ได้สองใบ · ใช้แบบ `strip` จะได้ **4 แถบต่อกระดาษหนึ่งแผ่น**
  ประหยัดหมึกกับกระดาษครึ่งหนึ่งเทียบกับพิมพ์ทีละใบ
- `"qrMode": "off"` — ยังไม่มีเว็บให้ QR ชี้ไป · เปิดเป็น `"later"` พร้อมใส่ `baseUrl`
  เมื่อทำส่วนอัปโหลดเสร็จ · **QR ที่สแกนแล้วพาไปหน้าว่าง แย่กว่าไม่มี QR**

เริ่มบูธ

```sh
cd photobooth && npm start
```

ตั้งค่าอยู่ให้เปิดแบบหน้าต่าง จะได้สลับไปแก้ไฟล์ได้

```sh
BOOTH_WINDOWED=1 npm start
```

## 6. ตรวจก่อนเสนอลูกค้า

1. **วัดด้วยไม้บรรทัด** — ตัดออกมาแล้วต้องได้ 102 × 152 มม. (4×6 นิ้ว) ±1 มม.
   ถ้าเล็กกว่านั้นชัดเจน แปลว่าไดรเวอร์ย่อให้ ให้ไปดูที่ **Scale / มาตราส่วน**
   ในหน้าตั้งค่าเครื่องพิมพ์ว่าเป็น 100% ไม่ใช่ "Fit to page"
2. **กระดาษ** — กระดาษถ่ายเอกสารธรรมดาสีจะซีดและหมึกซึม
   ใช้ **กระดาษ inkjet matte 120–180 แกรม** ราคาไม่แพงแต่ต่างกันคนละเรื่อง
   ถ้าจะให้ใกล้ของจริงที่สุดใช้ **กระดาษโฟโต้ glossy**
3. **สี** — สีบนจอกับสีที่ออกจากเครื่องไม่ตรงกัน พิมพ์ทดสอบหนึ่งใบแล้วปรับ
   ความสว่างของเอฟเฟคที่จะใช้จริง ก่อนพิมพ์ให้ลูกค้าดู
4. **แสง** — เว็บแคมไวต่อแสงมากกว่ากล้องจริง · ไฟ LED ส่องหน้าตรง ๆ ดวงเดียว
   ทำให้ภาพดีขึ้นกว่าการเพิ่มความละเอียดกล้องมาก

## 7. ข้อจำกัดของชุดเดโม — บอกลูกค้าตรง ๆ ได้เลย

| | ชุดเดโมตอนนี้ | ของจริงเมื่อซื้อ dye-sub |
|---|---|---|
| เวลาต่อแผ่น | ~40–60 วินาที (อิงค์เจ็ท A4) | ~12 วินาที |
| ต้องตัดเอง | ใช่ (มีเส้นตัดให้) | ไม่ต้อง ออกมาเป็นใบพอดี |
| กันน้ำ/ลายนิ้วมือ | ไม่ | ใช่ มีเคลือบผิวในตัว |
| ต้นทุนต่อแผ่น | ~3–6 บาท | ~10–15 บาท |
| คุณภาพกล้อง | เว็บแคม | กล้องจริง / มือถือ |

**สิ่งที่เดโมพิสูจน์ได้จริงและเป็นหัวใจของสินค้า**: ผังแผ่น เอฟเฟค ธีมตามงาน
ชื่องานบนแผ่น ความเร็วของขั้นตอน และหน้าตาของของที่แขกได้ถือกลับบ้าน
— สามอย่างที่เหลือ (ความเร็ว ความทน การตัด) แก้ด้วยการซื้อเครื่อง ไม่ใช่ด้วยการเขียนโค้ดเพิ่ม
