# แอปสไลด์โชว์สำหรับ Google TV

เปิดแล้วขึ้นสไลด์โชว์ทันที ไม่มีหน้าล็อกอิน ไม่มีแถบที่อยู่ ไม่ต้องพิมพ์อะไร
ด้วยรีโมตในวันงาน

ทั้งแอปคือ `WebView` ตัวเดียวที่ชี้ไปหน้า `/slideshow` ของเซิร์ฟเวอร์เดียวกับที่
แขกใช้ — **ไม่มีโค้ดสไลด์โชว์ซ้ำสองชุด** แก้ที่เว็บที่เดียว ทีวีได้ตามทันทีโดย
ไม่ต้องติดตั้ง APK ใหม่

## ทำไมต้องมีแอป ทั้งที่มีเว็บอยู่แล้ว

Google TV **ไม่มีเบราว์เซอร์ติดมาให้** และต่อให้ติดตั้งเบราว์เซอร์เพิ่ม ก็ยังต้อง
พิมพ์ที่อยู่ด้วยรีโมตทุกครั้ง แถมต้องสู้กับ screensaver ที่จะเด้งมาระหว่างงาน

| ปัญหาบน Google TV | แอปนี้แก้ยังไง |
|---|---|
| ไม่มีเบราว์เซอร์ | แอปมี WebView ในตัว |
| พิมพ์ที่อยู่ด้วยรีโมตลำบาก | ที่อยู่ฝังมาแล้ว กดเปิดแล้วโหลดเอง |
| จอดับ / screensaver ขึ้นกลางงาน | `FLAG_KEEP_SCREEN_ON` ตลอดเวลาที่แอปเปิด |
| มีแถบเบราว์เซอร์บังจอ | เต็มจอแบบ immersive ไม่มีขอบ |
| วิดีโอไม่เล่นเอง | `setMediaPlaybackRequiresUserGesture(false)` |
| เน็ตสะดุดแล้วขึ้นหน้า error ค้าง | ลองใหม่เองเรื่อย ๆ และสลับไปที่อยู่สำรอง |

## ที่อยู่ที่แอปจะลอง (ตามลำดับ)

1. ที่อยู่ที่ตั้งเองในแอป (ถ้าเคยตั้ง) — กดปุ่ม **MENU** บนรีโมตเพื่อแก้
2. `https://wedding.shafiq-lap.com/slideshow`
3. `http://192.168.2.2:18090/slideshow` ← ทางสำรองในวง LAN

ข้อ 3 มีไว้เผื่อกรณีที่เจอมาแล้วจริง: DNS ของเครือข่ายที่สถานที่จัดงานไม่รู้จัก
โดเมนนี้ หรือ hairpin NAT ใช้ไม่ได้ **ข้อนี้จะใช้ได้ก็ต่อเมื่อ**ทีวีอยู่วงเดียวกับ NAS
และรันแอปด้วย `sudo ./scripts/deploy-nas.sh --lan`

แก้ที่อยู่ถาวรได้ที่ `app/src/main/res/values/strings.xml` แล้ว build ใหม่

## เอา APK มาจากไหน

**วิธีที่ 1 — ให้ GitHub build ให้** (ไม่ต้องลงอะไรบนเครื่องตัวเอง)

ไปที่แท็บ **Actions** บน GitHub → **Build TV APK** → **Run workflow**
เสร็จแล้วโหลด artifact ชื่อ `wedding-slideshow-tv`

**วิธีที่ 2 — build เอง**

```bash
cd tv
echo "sdk.dir=$ANDROID_HOME" > local.properties
gradle :app:assembleDebug
# ได้ไฟล์ที่ app/build/outputs/apk/debug/app-debug.apk
```

## ติดตั้งลง Google TV

APK เซ็นด้วยกุญแจ debug จึงติดตั้งได้เลย แต่ต้องเปิดให้เครื่องรับแอปจากนอก Play Store ก่อน

1. **Settings → System → About** แล้วกดที่ **Android TV OS build** ติดกัน 7 ครั้ง
   จนขึ้นว่าเป็นนักพัฒนาแล้ว
2. **Settings → System → Developer options** → เปิด **USB debugging** (หรือ **Network debugging**)
3. **Settings → Apps → Security & restrictions → Unknown sources** → อนุญาตแอปที่จะใช้ส่งไฟล์

จากนั้นเลือกวิธีส่งไฟล์

| วิธี | ทำยังไง |
|---|---|
| **adb ผ่าน Wi-Fi** (แนะนำ) | ดูไอพีของทีวีที่ Settings → Network แล้วรัน `adb connect <ไอพีทีวี>:5555` ตามด้วย `adb install -r app-debug.apk` |
| **แอป Downloader** | ติดตั้ง Downloader (AFTVnews) จาก Play Store บนทีวี แล้วใส่ลิงก์ตรงของไฟล์ APK |
| **Send files to TV** | ติดตั้งทั้งบนมือถือและบนทีวี แล้วส่งไฟล์ข้ามกัน |

ติดตั้งเสร็จแล้วแอปจะขึ้นในแถวแอปของหน้าโฮม ชื่อ **Wedding Slideshow**

## ⚠️ ต้องทดสอบบนทีวีเครื่องจริงก่อนวันงาน

APK นี้ยัง**ไม่เคยถูกรันบน Google TV จริง** — สร้างและตรวจโครงสร้างไฟล์แล้วว่าถูกต้อง
(มี `leanback-launchable-activity`, ไม่บังคับจอสัมผัส, เซ็นชื่อเรียบร้อย) แต่การทำงาน
จริงบนเครื่องยังไม่ได้พิสูจน์

**ทดสอบให้ครบก่อนวันงาน**

- [ ] ติดตั้งแล้วเห็นไอคอนบนหน้าโฮมของ Google TV
- [ ] เปิดแล้วขึ้นสไลด์โชว์เอง ไม่ต้องพิมพ์อะไร
- [ ] **ปล่อยทิ้งไว้ 30 นาที จอต้องไม่ดับและ screensaver ต้องไม่ขึ้น**
- [ ] วิดีโอในสไลด์โชว์เล่นเองโดยไม่ต้องกดอะไร
- [ ] ถอดสาย LAN / ปิด Wi-Fi ชั่วครู่ แล้วต่อกลับ — ต้องกลับมาเองโดยไม่ต้องแตะรีโมต
- [ ] กดปุ่ม MENU แล้วแก้ที่อยู่ได้

**ต้องมีแผนสำรองเสมอ** ถ้าแอปมีปัญหาหน้างาน ให้ต่อโน้ตบุ๊กเข้า HDMI แล้วเปิด Chrome
