# แอปสไลด์โชว์สำหรับ Google TV

เปิดแล้วขึ้นสไลด์โชว์ทันที ไม่มีหน้าล็อกอิน ไม่มีแถบที่อยู่ ไม่ต้องพิมพ์อะไร
ด้วยรีโมตในวันงาน

ทั้งแอปคือ `WebView` ตัวเดียวที่ชี้ไปหน้า `/slideshow` ของเซิร์ฟเวอร์เดียวกับที่
แขกใช้ — **ไม่มีโค้ดสไลด์โชว์ซ้ำสองชุด** แก้ที่เว็บที่เดียว ทีวีได้ตามทันทีโดย
ไม่ต้องติดตั้ง APK ใหม่

## ทำไมต้องมีแอป ทั้งที่มีเว็บอยู่แล้ว

Google TV **ไม่มีเบราว์เซอร์ติดมาให้** และต่อให้ติดตั้งเบราว์เซอร์เพิ่ม ก็ยังต้อง
พิมพ์ที่อยู่ด้วยรีโมตทุกครั้ง แถมต้องสู้กับ screensaver ที่จะเด้งมาระหว่างงาน

| ปัญหาบน Google TV | แอปนี้แก้ยังไง |
|---|---|
| ไม่มีเบราว์เซอร์ | แอปมี WebView ในตัว |
| พิมพ์ที่อยู่ด้วยรีโมตลำบาก | ที่อยู่ฝังมาแล้ว กดเปิดแล้วโหลดเอง |
| จอดับ / screensaver ขึ้นกลางงาน | `FLAG_KEEP_SCREEN_ON` ตลอดเวลาที่แอปเปิด |
| มีแถบเบราว์เซอร์บังจอ | เต็มจอแบบ immersive ไม่มีขอบ |
| วิดีโอไม่เล่นเอง | `setMediaPlaybackRequiresUserGesture(false)` |
| เน็ตสะดุดแล้วขึ้นหน้า error ค้าง | ลองใหม่เองเรื่อย ๆ และสลับไปที่อยู่สำรอง |

## 🚨 ต่อ 5G / เน็ตมือถือแล้วแอปใช้ไม่ได้

**อาการ**: ทีวีต่อผ่านเน็ตมือถือ (5G, ฮอตสปอต, เราเตอร์ซิม) แล้วแอปขึ้นหน้า
`ERR_…` ค้าง หรือจอดำ ทั้งที่เปิดเว็บจากมือถือเครื่องอื่นได้ปกติ

**สาเหตุ** (แก้แล้วในเวอร์ชันหลัง 29 ส.ค. 2569): WebView เรียก `onPageFinished`
ให้ **หน้า error ของตัวเอง** ด้วย แอปเวอร์ชันเก่าจึงเข้าใจผิดว่า "โหลดสำเร็จแล้ว"
แล้วเลิกสลับที่อยู่ตลอดกาล — พอที่อยู่แรกล้มแวบเดียว แอปสลับไปที่อยู่สำรอง
`http://192.168.2.2:18090` แล้ว**ติดแหง็กอยู่ตรงนั้นถาวร** ซึ่งเป็นไอพีในวง LAN
ที่ไม่มีทางต่อติดจากเน็ตมือถือ จนกว่าจะบังคับปิดแอป

### แก้เดี๋ยวนี้โดยยังไม่ต้องลง APK ใหม่

1. **บังคับปิดแอปแล้วเปิดใหม่** — Settings → Apps → Wedding Slideshow → Force stop
   (ปิดด้วยปุ่ม Home เฉย ๆ ไม่พอ แอปยังอยู่ในหน่วยความจำพร้อมสถานะที่ค้างไว้)
2. ถ้ายังไม่ขึ้น กด **MENU** บนรีโมต แล้วใส่ที่อยู่นี้ตรง ๆ
   `https://wedding.shafiq-lap.com/slideshow/menu?lite=1&tv=1` แล้วกดบันทึก

### ถ้ายังไม่ขึ้นอีก แปลว่าไม่ใช่ที่แอป

เอามือถือมาเครื่องหนึ่ง **ปิด Wi-Fi ให้เหลือแต่เน็ตมือถือ** แล้วเปิด
`https://wedding.shafiq-lap.com/healthz`

| เห็นอะไร | แปลว่า | ทำอะไรต่อ |
|---|---|---|
| `{"ok":true}` | เว็บเข้าได้จากนอกบ้านจริง ปัญหาอยู่ที่แอป | ทำสองข้อข้างบนซ้ำ หรือลง APK ตัวใหม่ |
| ต่อไม่ติด / หมุนค้าง | ไอพีบ้านเปลี่ยนแต่ระเบียน DNS ยังค้างที่เลขเก่า | `sudo ./scripts/cloudflare-ddns.sh` บน NAS ([รายละเอียด](../docs/07-shafiq-nas.md)) |
| หน้า Synology | nginx ไม่ได้ส่งต่อไปหาแอป | `sudo ./scripts/diagnose-nas.sh` ดูข้อ 6.5 กับ 8 |

### ปุ่มบนรีโมตที่ใช้เปิดหน้าตั้งค่า

รีโมต Google TV/Chromecast **ไม่มีปุ่ม MENU** ตั้งแต่ 1.2 เป็นต้นไปจึงเปิดได้ด้วย

- **ปุ่ม OK** — ใช้ได้เฉพาะตอนจอขึ้นข้อความ "เชื่อมต่อไม่ได้" (ตอนสไลด์โชว์ทำงานปกติ
  ปุ่มนี้ยังเป็นของหน้าเมนูเหมือนเดิม ไม่ถูกแย่ง)
- ปุ่ม **MENU** / **SETTINGS** / **INFO** ถ้ารีโมตมี

ถ้าเข้าไม่ได้จริง ๆ ทางสุดท้ายคือ Settings → Apps → Wedding Slideshow → **Clear data**
ซึ่งล้างที่อยู่ที่บันทึกไว้ แล้วแอปกลับไปใช้ค่าเริ่มต้น

### เวอร์ชันใหม่แก้อะไรไปบ้าง

- หน้า error ของ WebView ไม่ถูกนับเป็น "โหลดสำเร็จ" อีกต่อไป — แอปจึงวนกลับมาลอง
  โดเมนสาธารณะซ้ำได้เสมอ ไม่ติดแหง็กอยู่กับไอพีในวง LAN
- ที่อยู่ที่เคยใช้ได้แล้วล้ม **2 ครั้งติดกัน** ถึงจะยอมสลับ — เน็ตสะดุดแวบเดียว
  กลางงานจะไม่พาแอปหนีไปที่อยู่ที่ใช้ไม่ได้
- ใบรับรองมีปัญหา (นาฬิกาทีวีเพี้ยน / cert หมดอายุ) เดิมทำให้แอปค้างจอดำเงียบ ๆ
  ตอนนี้ปฏิเสธแล้วลองใหม่ **และไม่ยอมข้ามการตรวจใบรับรองเด็ดขาด**
- เซิร์ฟเวอร์ตอบ 502 (คอนเทนเนอร์กำลังรีสตาร์ท) นับเป็นล้มแล้วลองใหม่ ไม่ค้างหน้า error
- **บนจอบอกสาเหตุด้วย** เช่น `สาเหตุ: net::ERR_NAME_NOT_RESOLVED` — อ่านจากทีวี
  ได้เลยว่าติดที่ DNS, ที่พอร์ต, หรือที่ใบรับรอง โดยไม่ต้องต่อคอมมาดู

จากการไล่ตรวจรอบสอง (1.2) ยังแก้เพิ่มอีก

- ตอนต่อไม่ติด หน้าเว็บถูก **ซ่อน** ไม่ใช่โหลดหน้าเปล่าทับ — วิธีเดิมทำให้ปุ่มย้อนกลับ
  พาย้อนไปหน้าเปล่าทีละหน้าแทนที่จะกลับหน้าเมนู และยิ่งเน็ตสะดุดบ่อยยิ่งสะสมเพิ่ม
- กด Home ออกจากแอปแล้ว **เสียงจากคลิปที่แขกส่งมาไม่ดังต่อ** อีกแล้ว
- พิมพ์ที่อยู่โดยลืมใส่ `https://` แอปเติมให้เอง (เดิมบันทึกค่าที่โหลดไม่ขึ้นถาวร)
- ที่อยู่ซ้ำในรายการถูกตัดออก ไม่เสียเที่ยวลองสองรอบ
- วัดจังหวะกดย้อนกลับสองครั้งด้วยนาฬิกาที่นับตั้งแต่บูต ไม่ใช่นาฬิกาโลก — ทีวีที่ไม่มี
  นาฬิกาสำรองจะซิงก์เวลาหลังบูต ถ้าเวลากระโดดถอยหลังพอดี กดย้อนกลับครั้งเดียวจะ
  ออกจากแอปทันที
- ปิดแอปแล้วถอด WebView ออกจากหน้าจอก่อนทำลาย ตามที่เอกสาร Android กำหนด
- ประกาศ `configChanges` ให้ครบ ทีวีเปลี่ยนภาษา/ความหนาแน่นจอแล้วสไลด์โชว์ไม่เริ่มใหม่

## เปิดมาแล้วเจออะไร

แอปเปิดที่ **หน้าเมนู** ก่อน ให้เลือกว่าจะเอาสไลด์โชว์แบบไหน

| ปุ่มบนรีโมต | ทำอะไร |
|---|---|
| ลูกศร ซ้าย/ขวา/บน/ล่าง | เลื่อนเลือกระหว่างสองแบบ |
| OK | เปิดแบบที่เลือก |
| ย้อนกลับ | กลับมาหน้าเมนูเพื่อเลือกใหม่ |
| ย้อนกลับ (ตอนอยู่หน้าเมนูแล้ว) | กดสองครั้งเพื่อออกจากแอป |
| MENU | แก้ที่อยู่ที่แอปจะเปิด |

เปลี่ยนรูปแบบกลางงานได้ตลอด ไม่ต้องปิดแอปหรือแตะอะไรนอกจากรีโมต

## ที่อยู่ที่แอปจะลอง (ตามลำดับ)

1. ที่อยู่ที่ตั้งเองในแอป (ถ้าเคยตั้ง) — กดปุ่ม **MENU** บนรีโมตเพื่อแก้
2. `https://wedding.shafiq-lap.com/slideshow/menu?lite=1&tv=1`
3. `http://192.168.2.2:18090/slideshow/menu?lite=1&tv=1` ← ทางสำรองในวง LAN

ข้อ 3 มีไว้เผื่อกรณีที่เจอมาแล้วจริง: DNS ของเครือข่ายที่สถานที่จัดงานไม่รู้จัก
โดเมนนี้ หรือ hairpin NAT ใช้ไม่ได้ **ข้อนี้จะใช้ได้ก็ต่อเมื่อ**ทีวีอยู่วงเดียวกับ NAS
และรันแอปด้วย `sudo ./scripts/deploy-nas.sh --lan`

แก้ที่อยู่ถาวรได้ที่ `app/src/main/res/values/strings.xml` แล้ว build ใหม่

## เอา APK มาจากไหน

**วิธีที่ 1 — ให้ GitHub build ให้** (ไม่ต้องลงอะไรบนเครื่องตัวเอง)

ไปที่แท็บ **Actions** บน GitHub → **Build TV APK** → **Run workflow**
เสร็จแล้วโหลด artifact ชื่อ `wedding-slideshow-tv`

**วิธีที่ 2 — build เอง**

```bash
cd tv
echo "sdk.dir=$ANDROID_HOME" > local.properties
gradle :app:assembleDebug
# ได้ไฟล์ที่ app/build/outputs/apk/debug/app-debug.apk
```

## ติดตั้งลง Google TV

APK เซ็นด้วยกุญแจ debug จึงติดตั้งได้เลย แต่ต้องเปิดให้เครื่องรับแอปจากนอก Play Store ก่อน

1. **Settings → System → About** แล้วกดที่ **Android TV OS build** ติดกัน 7 ครั้ง
   จนขึ้นว่าเป็นนักพัฒนาแล้ว
2. **Settings → System → Developer options** → เปิด **USB debugging** (หรือ **Network debugging**)
3. **Settings → Apps → Security & restrictions → Unknown sources** → อนุญาตแอปที่จะใช้ส่งไฟล์

จากนั้นเลือกวิธีส่งไฟล์

### วิธีที่ 1 — ส่งจากมือถือ ⭐ ง่ายที่สุด ไม่ต้องใช้คอมเลย

1. ติดตั้งแอป **Send files to TV** จาก Play Store **ทั้งบนมือถือและบนทีวี**
2. เปิดแอปบนทีวี เลือก **Receive**
3. เปิดแอปบนมือถือ เลือก **Send** → เลือกไฟล์ `app-debug.apk` → เลือกชื่อทีวี
4. ทีวีจะถามว่าจะติดตั้งไหม กด Install

ทั้งสองเครื่องต้องอยู่ Wi-Fi วงเดียวกัน

### วิธีที่ 2 — ส่งจาก Windows ด้วย adb

Windows ไม่มี `adb` มาให้ ต้องโหลดชุดเครื่องมือก่อน ไม่ต้องติดตั้ง แตกไฟล์แล้วใช้ได้เลย

```powershell
cd $HOME\Downloads
Invoke-WebRequest -Uri "https://dl.google.com/android/repository/platform-tools-latest-windows.zip" -OutFile "platform-tools.zip"
Expand-Archive -Path "platform-tools.zip" -DestinationPath "." -Force
cd platform-tools
```

จากนั้นดูไอพีของทีวีที่ **Settings → Network & Internet** แล้วรัน (แทนเลขไอพีเป็นของทีวีเครื่องคุณ)

```powershell
.\adb.exe connect 192.168.2.16:5555
```

ทีวีจะเด้งถามว่า *"Allow USB debugging?"* ให้กด **Always allow** แล้วค่อยติดตั้ง

```powershell
.\adb.exe install -r $HOME\Downloads\app-debug.apk
```

ต้องขึ้นว่า `Success`

> ⚠️ ต้องมี `.\` นำหน้า `adb.exe` เสมอ — PowerShell ไม่รันไฟล์ในโฟลเดอร์ปัจจุบัน
> ถ้าไม่ระบุพาธ และเลขไอพี **ห้ามใส่วงเล็บ `< >`** ครอบ ให้พิมพ์เลขล้วน ๆ

### วิธีที่ 3 — แอป Downloader บนทีวี

ติดตั้ง **Downloader** (AFTVnews) จาก Play Store บนทีวี แล้วใส่ลิงก์ตรงของไฟล์ APK
เหมาะเมื่อมีที่วางไฟล์ให้โหลดผ่านเว็บอยู่แล้ว

ติดตั้งเสร็จแล้วแอปจะขึ้นในแถวแอปของหน้าโฮม ชื่อ **Wedding Slideshow**

## ⚠️ ต้องทดสอบบนทีวีเครื่องจริงก่อนวันงาน

APK รันบนทีวีจริงแล้ว และบั๊กตอนต่อ 5G ข้างบนก็เจอจากการใช้จริงนั่นเอง
ตรรกะการวนหาที่อยู่มีเทสต์กำกับแล้วที่ `test/tv-app.test.js` (คอมไพล์ไฟล์ Java
ตัวจริงแล้วยิง callback ของ WebView ใส่) แต่**เทสต์แทนการลองบนเครื่องจริงไม่ได้**
— รายการข้างล่างยังต้องไล่ด้วยมือทุกครั้งที่ลง APK ตัวใหม่
