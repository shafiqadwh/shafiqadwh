# บทที่ 3 · ตั้งค่างานและพิมพ์การ์ด QR

## 1. ตรวจ `BASE_URL` ก่อนทุกอย่าง

QR code สร้างจากค่า `BASE_URL` ใน `.env` ถ้าค่านี้ผิด การ์ดที่พิมพ์ไปแล้ว
ใช้ไม่ได้ทั้งหมด

```env
BASE_URL=https://wedding.shafiq-lap.com
```

ห้ามใส่ `/` ปิดท้าย ห้ามใส่ `http://` (ต้องเป็น https)
แก้แล้วรีสตาร์ท `sudo docker compose up -d`

## 2. ปรับข้อความและลิมิตให้เข้ากับงาน

| ค่าใน `.env` | ความหมาย | ค่าที่แนะนำ |
|---|---|---|
| `COUPLE_NAMES` | ชื่อบ่าวสาว โผล่บนหัวเว็บและการ์ด | `Sofwan & 'Aishah Nadhirah` |
| `EVENT_MONOGRAM` | อักษรย่อตัวใหญ่บนการ์ด (เว้นว่าง = ย่อให้เอง) | `S & N` |
| `EVENT_DATE` | วันที่ โผล่ใต้ชื่อ | `29.08.2026` |
| `EVENT_VENUE` | สถานที่ พิมพ์ไว้ท้ายการ์ด | `Hasanah Restaurant (ร้านอาหารฮาซานะห์) Sateng, Yala` |
| `EVENT_TIME` | เวลา พิมพ์ต่อจากสถานที่ | `11.00 - 16.00` |
| `MAX_IMAGE_MB` | ขนาดรูปสูงสุด | 25 (พอสำหรับมือถือทุกรุ่น) |
| `MAX_VIDEO_MB` | ขนาดวิดีโอสูงสุด | 300 |
| `MAX_VIDEO_SECONDS` | ความยาวคลิปสูงสุด | 180 |
| `MAX_FILES_PER_UPLOAD` | เลือกได้กี่ไฟล์ต่อครั้ง | 20 |
| `DEFAULT_LANGUAGE` | ภาษาเริ่มต้นเมื่อเดาจากเครื่องแขกไม่ได้ | `th` |

**เรื่องภาษา** — เว็บเลือกภาษาให้อัตโนมัติตามลำดับนี้

1. ภาษาที่แขกกดเลือกเอง (จำไว้ในเครื่อง 180 วัน)
2. ภาษาของเครื่อง — มือถือมาเลเซียได้ Bahasa Melayu, ฝรั่งได้ English โดยไม่ต้องกดอะไร
3. ถ้าเดาไม่ได้ ใช้ `DEFAULT_LANGUAGE` (ไทย)

ปุ่ม **TH / BM / EN** อยู่มุมบนขวาทุกหน้า แขกกดสลับเองได้ตลอด

## 3. เปิดช่วงเวลาอัพโหลด (ถ้าต้องการ)

ปกติเปิดตลอด ถ้าอยากให้เปิดเฉพาะวันงาน

```env
UPLOAD_WINDOW=2026-08-29 08:00 / 2026-08-30 23:59
```

นอกช่วงนี้ ปุ่มอัพโหลดจะหายไปและขึ้นข้อความ "ยังไม่เปิดให้อัพโหลด"
แต่ยังดูรูปได้ตามปกติ

ถ้าอยากเปิด/ปิดแบบทันทีหน้างาน ใช้สวิตช์ในหน้า `/admin` แทน

## 4. เรื่องเซ็นเซอร์รูป

ค่าเริ่มต้นคือ **ไม่เซ็นเซอร์** — รูปขึ้นทันที ซึ่งสนุกกว่าและไม่ต้องมีคนคอยกดอนุมัติ

ถ้าเปลี่ยนใจ ไปที่ `/admin` → ติ๊ก **ตรวจสอบก่อนขึ้นแสดง** → กดตกลง
หลังจากนั้นรูปใหม่ทุกใบจะรอคุณกด "อนุมัติ" ก่อน
(คนอัพโหลดจะเห็นข้อความว่า "รอเจ้าภาพตรวจสอบ" ไม่งงว่ารูปหายไปไหน)

ต่อให้ไม่เปิดโหมดนี้ คุณก็ลบรูปได้ทันทีจากมือถือที่หน้า `/admin`

## 5. พิมพ์การ์ด QR

เข้า `https://.../admin` → ล็อกอิน → กด **การ์ด QR สำหรับพิมพ์**

หน้าที่ได้จะมีการ์ดขนาด **A5 สองใบต่อหนึ่งหน้ากระดาษ A4** แต่ละใบมี

- ชื่อบ่าวสาวและวันที่
- QR code ขนาด 62 มม. (สแกนติดง่ายแม้แสงน้อยในงานเลี้ยง)
- คำอธิบายครบ **3 ภาษา** ไทย / มลายู / อังกฤษ
- ที่อยู่เว็บเป็นตัวหนังสือ เผื่อกล้องบางเครื่องสแกนไม่ติด

กด **สั่งพิมพ์** → ในหน้าต่างพิมพ์เลือก

- ขนาดกระดาษ: A4
- Margins: None / Minimum
- ติ๊ก **Background graphics** (ไม่งั้น QR อาจจางเกินไป)

ปุ่ม **PNG** ใช้เมื่ออยากเอา QR ไปวางในโปสเตอร์หรือการ์ดเชิญที่ออกแบบเอง

### พิมพ์กี่ใบดี

| จุดวาง | จำนวน |
|---|---|
| โต๊ะแขก | 1 ใบต่อโต๊ะ (ตั้งในกรอบอะคริลิกจะไม่ล้ม) |
| โต๊ะลงทะเบียน | 2–3 ใบ |
| ป้ายใหญ่หน้างาน / ข้างเวที | 1 ป้าย (ใช้ไฟล์ PNG ขยายเป็น A3) |
| สำรอง | 5 ใบ |

**เคล็ดลับ**: สแกนการ์ดที่พิมพ์เสร็จแล้วด้วยมือถือจริง 1 ครั้งก่อนแจก
เพื่อยืนยันว่าหมึกไม่จางและลิงก์ถูกต้อง

## 6. ทดสอบครั้งสุดท้ายก่อนแจกการ์ด

- [ ] สแกน QR จากการ์ดที่พิมพ์แล้ว ด้วย iPhone → เปิดเว็บได้
- [ ] สแกนด้วย Android → เปิดเว็บได้
- [ ] อัพโหลดรูป 1 ใบ และวิดีโอ 1 คลิป จากมือถือจริงผ่าน 4G
- [ ] เปลี่ยนภาษาเป็น BM แล้วอ่านรู้เรื่อง
- [ ] เขียนคำอวยพร 1 ข้อความ

## งานที่จัดหลายวันคนละที่

การ์ดมีสองแบบ พิมพ์จากหน้าแอดมินได้ทั้งคู่

| แบบ | ที่อยู่ | บรรทัดสถานที่ | ใช้เมื่อไหร่ |
|---|---|---|---|
| เต็ม | `/admin/qr` | มีชื่อร้านและเวลา | วันงานเลี้ยงที่ร้าน |
| ไม่ระบุสถานที่ | `/admin/qr?venue=0` | ไม่มี | วันที่จัดที่บ้าน หรือพิมพ์ชุดเดียวใช้ทุกวัน |

**ที่อยู่เว็บกับ QR เหมือนกันทั้งสองแบบ** รูปจากทุกวันจึงมารวมอยู่ที่เดียวกัน
ต่างกันแค่บรรทัดล่างของการ์ด

> การ์ดที่พิมพ์ชื่อร้านไว้ตายตัว ถ้าเอาไปวางในวันที่จัดที่บ้าน จะบอกสถานที่ผิด
> ให้แขก — ปัญหาเล็กแต่เจอทุกครั้งที่งานจัดหลายวัน

ถ้า `EVENT_DATE` เป็นวันเดียว แต่งานกินเวลาหลายวัน ให้ตั้งเป็นช่วงแทน
เพราะวันนี้ปรากฏทั้งบนการ์ด บนหัวเว็บ และบนการ์ดชื่อคู่บ่าวสาวในสไลด์โชว์

```bash
sudo ./scripts/set-config.sh "EVENT_DATE=27-29.08.2026"
sudo ./scripts/update.sh --env
```
