# บทที่ 6 · เช็คลิสต์วันงาน

พิมพ์หน้านี้ออกมาหรือเปิดค้างไว้ในมือถือ

---

## 🗓 1 สัปดาห์ก่อนงาน

- [ ] เว็บเปิดได้จาก **4G/5G** (ปิด Wi-Fi ทดสอบ) เห็นแม่กุญแจ 🔒
- [ ] ใบรับรอง HTTPS ยังไม่หมดอายุ — DSM → Security → Certificate ดูวันหมดอายุ
- [ ] ทดสอบอัพโหลด **รูปจาก iPhone** (ไฟล์ .HEIC ต้องขึ้นแสดงได้ปกติ)
- [ ] ทดสอบอัพโหลด **วิดีโอจาก iPhone** (.mov — ตัวที่พังบ่อยที่สุด)
- [ ] ทดสอบอัพโหลด **รูปและวิดีโอจาก Android**
- [ ] เปิดวิดีโอที่ iPhone ส่งขึ้นมา **ด้วยเครื่อง Android** — ต้องเล่นได้
- [ ] ทดสอบเลือกหลายไฟล์พร้อมกัน 10 ไฟล์
- [ ] เปลี่ยนภาษาเป็น **BM** และ **EN** อ่านรู้เรื่องทั้งสองภาษา
- [ ] เขียนคำอวยพรพร้อมแนบรูปได้
- [ ] เช็คพื้นที่ว่าง `df -h /volume1` — ควรเหลือ **อย่างน้อย 50 GB**
- [ ] `BASE_URL` ใน `.env` ตรงกับที่อยู่จริง
- [ ] **สั่งพิมพ์การ์ด QR** แล้วสแกนใบที่พิมพ์จริงหนึ่งครั้ง
- [ ] NAS ไม่ได้ตั้ง auto-shutdown / hibernate ในช่วงวันงาน
  (Control Panel → Hardware & Power → Power Schedule)

## 🗓 1 วันก่อนงาน

- [ ] ลบรูปทดสอบทั้งหมดออกจาก `/admin`
- [ ] ตั้ง `UPLOAD_WINDOW` (ถ้าใช้) หรือเปิดสวิตช์อัพโหลดไว้
- [ ] `sudo docker compose ps` — สถานะต้องเป็น `Up (healthy)`
- [ ] ล็อกอิน `/admin` ค้างไว้ในมือถือเจ้าภาพ **และ** มือถือคนช่วยอีก 1 คน
- [ ] ชาร์จโน้ตบุ๊กเครื่องฉายจอ + เตรียมสาย HDMI และตัวแปลง
- [ ] เตรียมการ์ด QR แยกใส่ซองตามโต๊ะเรียบร้อย
- [ ] จดที่อยู่เว็บและรหัส `/admin` ใส่กระดาษไว้ในกระเป๋า (เผื่อมือถือแบตหมด)
- [ ] แจ้งพิธีกรให้ประกาศชวนแขกสแกน QR ช่วงต้นงาน

## 🎉 วันงาน — ก่อนแขกมา 30 นาที

- [ ] เปิดเว็บจากมือถือ 1 เครื่อง เช็คว่ายังขึ้นปกติ
- [ ] เปิดหน้า `/slideshow` เต็มจอบนโปรเจกเตอร์/ทีวี
- [ ] อัพโหลดรูปทดสอบ 1 ใบ → ขึ้นจอภายใน 30 วินาที → แล้วลบทิ้ง
- [ ] วางการ์ด QR ครบทุกโต๊ะ + จุดลงทะเบียน
- [ ] เช็ค Wi-Fi ของสถานที่ (ถ้ามี) และแจ้งรหัสให้แขก

## 🎉 ระหว่างงาน

- [ ] ดูจอสไลด์โชว์เป็นระยะ — มีรูปไม่เหมาะให้กด **ลบ** ที่ `/admin`
- [ ] ช่วงกลางงาน ลองเช็คว่ามีรูปเข้ามาจริง (`/admin` → ตัวเลขสถิติ)
- [ ] ถ้าไม่มีใครส่งรูปเลย → ให้พิธีกรประกาศซ้ำ หรือเดินชวนโต๊ะแรก ๆ
- [ ] แขกบางคนอาจถามว่า "ต้องโหลดแอปไหม" → **ไม่ต้อง สแกนแล้วใช้ได้เลย**

## 🌙 หลังงานจบ

- [ ] ปิดสวิตช์ **เปิดให้แขกอัพโหลด** ที่ `/admin`
- [ ] ดาวน์โหลด ZIP ทั้งหมด ([บทที่ 5](05-download-backup.md))
- [ ] สำรองข้อมูลลงที่อื่นอย่างน้อย 1 ที่ ภายใน 24 ชั่วโมง
- [ ] แชร์ลิงก์ให้แขกเข้ามาดูรูปย้อนหลังได้อีกสัก 1–2 เดือน

---

## 🚨 แก้ปัญหาเฉพาะหน้า

| อาการ | ทำอะไร |
|---|---|
| แขกอัพโหลดไม่ได้ทุกคน | เช็คว่าคอนเทนเนอร์ยังรัน: `sudo docker compose ps` → ถ้าไม่ขึ้น `Up` ให้ `sudo docker compose up -d` |
| อัพวิดีโอไม่ผ่าน แต่รูปได้ | ลิมิต nginx หาย — ทำ[ข้อ 5 ของบทที่ 2](02-ddns-reverse-proxy.md#5--แก้ลิมิตขนาดอัพโหลดของ-nginx-ห้ามข้าม) ซ้ำแล้วรีสตาร์ท nginx |
| เว็บเข้าไม่ได้จากข้างนอก แต่ใน Wi-Fi บ้านได้ | เน็ตบ้านล่ม หรือ IP เปลี่ยนแล้ว DDNS ยังไม่อัปเดต → เช็คที่ Control Panel → External Access |
| จอสไลด์โชว์ค้าง | กด F5 หนึ่งครั้ง — รูปทั้งหมดยังอยู่ครบ |
| รูปขึ้นช้ามาก | เน็ตในงานแน่น → เปลี่ยนเครื่องฉายจอให้ชี้ไป IP ใน LAN ตรง ๆ |
| ดิสก์ใกล้เต็ม | `/admin` → ลบวิดีโอที่ยาวผิดปกติออกก่อน หรือลด `MAX_VIDEO_MB` |
| ลืมรหัส `/admin` | แก้ `ADMIN_PASSWORD` ใน `.env` → `sudo docker compose up -d` (เซสชันเดิมยังใช้ได้จนหมดอายุ) |

**เบอร์ฉุกเฉินของตัวเอง**: จดชื่อคนที่ดูแลเรื่องนี้ไว้ให้พิธีกรและเจ้าภาพรู้
เผื่อระหว่างงานมีอะไรผิดพลาดจะได้เรียกถูกคน
