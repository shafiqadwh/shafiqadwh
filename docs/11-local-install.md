# ติดตั้งและตรวจเว็บแชร์รูปกับ Photo Booth

ใช้ซอร์สทั้งโครงการด้วยกัน: photobooth ต้องใช้ shared และ assets จากโฟลเดอร์ด้านบนด้วย
ต้องมี Node.js 22 ขึ้นไปและ npm; รอบนี้ติดตั้งและทดสอบบน Windows ด้วย Node.js 24.16.0

## Windows

เปิด PowerShell ในโฟลเดอร์โครงการ:

```powershell
./scripts/install-local.ps1
Copy-Item .env.example .env
```

หากมี .env อยู่แล้วให้แก้ไฟล์เดิม ไม่คัดลอกทับ ตั้งค่าอย่างน้อย:

```dotenv
ADMIN_PASSWORD=เปลี่ยนเป็นรหัสเฉพาะของคุณอย่างน้อย8ตัว
BOOTH_KEY=replace-with-a-random-secret-at-least-16-ASCII-characters
BASE_URL=http://localhost:3000
```

ค่า BOOTH_KEY ตัวอย่างต้องเปลี่ยนก่อนใช้งานจริง คีย์เดียวกันต้องตั้งในหน้าตั้งค่าบูธ
เปิดเว็บ:

```powershell
npm.cmd start
```

คำสั่ง start อ่าน .env ให้แล้ว ตัวแปร environment ที่ตั้งไว้ก่อนมีลำดับสูงกว่า .env
เปิด PowerShell อีกหน้าต่างในโครงการเพื่อตรวจและเปิดบูธ:

```powershell
npm.cmd run check:booth
Set-Location photobooth
npm.cmd run install:electron
npm.cmd start
```

คำสั่ง install:electron โหลดตัวโปรแกรม Electron ประมาณ 150 MB ครั้งเดียว
npm ci ไม่โหลดให้ เพราะ Electron 44 เลิกใช้ postinstall แล้ว
install-local.ps1 เรียกให้แล้ว ขั้นนี้จำเป็นเฉพาะตอนติดตั้งด้วยมือ
ต้องรันตอนมีอินเทอร์เน็ต ไม่ใช่หน้างานที่ไม่มีเน็ต

ในหน้าตั้งค่าบูธ ตั้งที่อยู่เว็บให้ตรง BASE_URL และกุญแจให้ตรง BOOTH_KEY
เริ่มด้วยเว็บแคมและโหมดไฟล์/ไม่พิมพ์เพื่อทดสอบก่อนเลือกเครื่องพิมพ์จริง
คำสั่งตรวจเชื่อมต่อใช้เวลาไม่เกินประมาณ 10 วินาที ไม่อัปโหลดรูปหรือแสดงคีย์
ต้องอัปเดตส่วนเว็บด้วยจึงจะมี /api/booth/status; เว็บเก่าจะตอบ 404

localhost ใช้ทดสอบในคอมพิวเตอร์เท่านั้น มือถือสแกนแล้วจะเปิดไม่ได้
ก่อนใช้ในงานให้เปลี่ยน BASE_URL และที่อยู่ในบูธเป็นโดเมน HTTPS ที่มือถือเข้าถึงได้
หรือ IP เครื่องเซิร์ฟเวอร์ที่มือถือเข้าถึงผ่าน Wi-Fi เดียวกันสำหรับทดสอบ LAN
ตั้งที่อยู่ให้ถูกก่อนถ่าย เพราะ QR ที่พิมพ์แล้วเปลี่ยนตามค่าตั้งใหม่ไม่ได้
ติดตั้ง NAS/HTTPS ตาม docs/01-install-nas.md และ docs/02-ddns-reverse-proxy.md

## ทดสอบก่อนเปิดงาน

```powershell
npm.cmd run test:integration
```

ชุดนี้เปิดเซิร์ฟเวอร์ชั่วคราว ใช้รูปจำลองและโฟลเดอร์ข้อมูลแยก ตรวจคีย์ผิด/ถูก
อัปโหลดจริง ส่งซ้ำ เปิดหน้ารับรูป และตรวจไบต์ของไฟล์ดาวน์โหลด ไม่ใช้ข้อมูลลูกค้า
รวมทดสอบการปฏิเสธ redirect และการรักษารหัสรอบเมื่อถ่ายใหม่

ก่อนเปิดงานให้ถ่ายภาพด้วยอุปกรณ์จริง ส่งขึ้นเว็บ แล้วสแกน QR จากมือถือแขก
ตรวจดาวน์โหลดและทดลองพิมพ์หนึ่งใบ ตัดอินเทอร์เน็ตทดลองหนึ่งรอบแล้วส่งคิวอีกครั้งหลังเชื่อมต่อ

## ผลรอบพัฒนา 9 กันยายน 2026

- ติดตั้ง npm ci ทั้งเว็บและ photobooth สำเร็จ
- แก้การส่งรูปไม่ให้ตาม redirect เพื่อไม่ส่งรูปและคีย์ไปผิดปลายทาง
- แก้ถ่ายใหม่ให้คงโฟลเดอร์ที่จองรหัสไว้ตลอด
- เพิ่มตรวจเชื่อมต่อแบบอ่านอย่างเดียว และสคริปต์ติดตั้ง dependencies ตาม lockfile
- ชุดทดสอบเดิมฝั่งเว็บ: 421 ข้อ ผ่าน 331 ล้มเหลว 77 ข้าม 13 บน Windows
  พบปัญหาคำสั่ง Linux และ cleanup ฐานข้อมูลที่ยังเปิดอยู่ จึงยังถือว่า full suite ไม่ผ่าน
- ยังไม่ยืนยันกล้องจริง เครื่องพิมพ์จริง หน้าจอ Electron หรือ Docker/NAS
- การทดสอบส่งซ้ำนี้ยืนยันกรณีส่งรูปชุดเดิม ไม่ได้แก้รหัสชนกันจากหลายบูธ
- ยังไม่แก้การกู้สถานะจ่ายเงินหรือคิวพิมพ์หลังโปรแกรมปิด

รุ่นนี้เป็นชุดปรับปรุงสำหรับทดสอบก่อนใช้งานจริง ยังไม่ได้ติดตั้ง NAS หรือ push GitHub
