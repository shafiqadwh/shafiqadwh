# Photo Studio — UX/UI refresh

## เปิดใช้งาน

ติดตั้งตาม docs/11-local-install.md แล้วดับเบิลคลิก START.cmd บน Windows:
1 เปิดเว็บแชร์รูป · 2 เปิด Photo Booth · 3 ตรวจการเชื่อมต่อเว็บ
ต้องเปิดหน้าต่างเว็บค้างไว้ หากต้องใช้เว็บและบูธในเครื่องเดียวกันให้เปิด START.cmd อีกครั้งแล้วเลือก 2

## ขั้นตอนใหม่

- แขกแชร์รูป: เลือกรูป → ตรวจรูปและยืนยันส่ง ชื่อเป็นตัวเลือก ไม่จำเป็นต้องกรอก
- บูธ: เริ่มถ่าย → ดูรูป → รับรูป ขั้นชำระเงินยังคงมีเมื่อเปิดขาย
- เชื่อมเว็บ: หน้าตั้งค่าบูธ → รับรูปผ่าน QR → กรอกที่อยู่เว็บและกุญแจ → ตรวจการเชื่อมต่อ → บันทึก
  ไม่ต้องเปิดแก้ settings.json สำหรับสองค่านี้อีก
- เจ้าหน้าที่: เมนูลัดพาไปเครื่องมือ รูปภาพ ตั้งค่า หน้าปก และวิดีโอได้โดยตรง
- ตั้งค่าจากจอช่างภาพด้วยปุ่ม “ตั้งค่าบูธ”; บูธจอเดียวใช้กดค้างที่ชื่องานตามเดิม

## การเปลี่ยนแปลง

ใช้หน้าตาสีน้ำเงินเข้มกับปุ่มสีเขียวอมฟ้าแบบเดียวกันทั่วเว็บและบูธ
หน้าแขกบนคอมแยกแผงแชร์รูปกับแกลเลอรี บนมือถือเรียงปุ่มเลือกรูปก่อนช่องชื่อ
ปรับหัวข้อ ระยะห่าง ขนาดปุ่ม สถานะ การโฟกัสคีย์บอร์ด และลดการเคลื่อนไหวตามค่าระบบ
ภาษาเดิมและสีธีมเฉพาะงานยังใช้ได้ แบบแผ่นพิมพ์และการชำระเงินไม่ได้เปลี่ยนวิธีทำงาน

แก้การอัปโหลดและการส่งคำอวยพรหยุดเมื่อ localStorage ถูกปิด ปุ่มเลือกไฟล์ใช้คีย์บอร์ดได้
การตรวจเชื่อมต่อไม่ส่งภาพ ไม่ตาม redirect และไม่แสดงกุญแจในข้อความผิดพลาด
ค่าปลายทางที่ไม่ถูกต้องไม่ถูกบันทึกทับ และสถานะตอบกลับเก่าไม่ทับค่าที่แก้ระหว่างตรวจ

## ตรวจสอบ

ชุด regression ด้านล่างผ่าน 35 ข้อ ข้าม 0 และคอมไพล์ EJS ผ่าน 17 template

คำสั่ง regression:

```powershell
node --test test/booth-system-smoke.test.js test/upload-storage.test.js photobooth/test/transfer-regressions.test.js photobooth/test/upload.test.js photobooth/test/connection.test.js photobooth/test/setup-form.test.js photobooth/test/booth.test.js
```

ตรวจเว็บจริงบนคอมและมือถือ 390px; ตรวจเลย์เอาต์หน้าบูธและตั้งค่าผ่าน browser preview ที่ใช้ข้อมูลจำลอง
preview นี้ใช้ตรวจการจัดวางเท่านั้น ไม่ใช่หลักฐานการทำงานของกล้องหรือ Electron
ทดสอบการบันทึกค่าจากฟอร์มด้วย DOM จำลองและการส่งรูปผ่านเซิร์ฟเวอร์จริงแยกกัน

ข้อจำกัด: Electron settings-screen test เปิดโปรแกรมไม่สำเร็จบนเครื่องทดสอบนี้
(process exit 3221225477) จึงล้ม 6 ข้อ ไม่ได้ข้ามหรือถือว่าผ่าน
