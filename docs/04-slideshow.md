# บทที่ 4 · ต่อจอ Slideshow ในงาน

หน้า `/slideshow` ออกแบบมาให้เปิดทิ้งไว้บนจอโปรเจกเตอร์หรือทีวีทั้งงาน
รูปที่แขกเพิ่งอัพโหลดจะ **แทรกขึ้นจอภายในไม่กี่วินาที** ซึ่งเป็นตัวกระตุ้น
ให้คนอื่นอยากส่งรูปตามมากที่สุด

---

## 1. เตรียมเครื่องฉาย

ใช้โน้ตบุ๊กเครื่องไหนก็ได้ต่อ HDMI เข้าทีวี/โปรเจกเตอร์

**ตั้งค่าที่ห้ามลืม**

- ปิด Screen saver และ Sleep (Windows: Settings → Power → Screen and sleep → Never)
- ปิดการแจ้งเตือน (Windows: Focus assist / macOS: Do Not Disturb)
- เสียบสายชาร์จไว้ตลอด
- ปิดการอัปเดตอัตโนมัติในวันงาน

## 1.5 ถ้าใช้ Google TV — มีแอปให้แล้ว

Google TV **ไม่มีเบราว์เซอร์ติดมาให้** และการพิมพ์ที่อยู่ด้วยรีโมตในวันงานคือ
จุดที่พลาดได้ง่ายที่สุด จึงมีแอปเล็ก ๆ ให้ติดตั้ง — เปิดแล้วขึ้นสไลด์โชว์ทันที
ไม่ต้องพิมพ์อะไร ไม่ดับจอ วิดีโอเล่นเอง เน็ตสะดุดก็กลับมาเอง

ขั้นตอนทั้งหมดอยู่ที่ [`tv/README.md`](../tv/README.md)

> แอปคือ WebView ที่ชี้มาหน้า `/slideshow` ตัวเดิม ไม่ได้เขียนสไลด์โชว์ขึ้นใหม่
> แก้หน้าเว็บที่เดียว ทีวีได้ตามทันทีโดยไม่ต้องลง APK ใหม่

**ยังต้องมีแผนสำรอง** — ต่อโน้ตบุ๊กเข้า HDMI แล้วเปิด Chrome เต็มจอตามหัวข้อถัดไป
ซ้อมทั้งสองทางไว้ อย่าพึ่งทางเดียว

## 2. เปิดแบบเต็มจอ

```bash
# Windows
chrome.exe --kiosk --incognito "https://wedding.ali-nurul.synology.me/slideshow"

# macOS
open -a "Google Chrome" --args --kiosk --incognito "https://wedding.ali-nurul.synology.me/slideshow"
```

หรือเปิดเว็บธรรมดาแล้วกด **F11**

> **แนะนำ**: ถ้าเครื่องฉายอยู่ในสถานที่เดียวกับ NAS ให้ชี้ไปที่ IP ใน LAN ตรง ๆ
> เช่น `http://192.168.2.2:18090/slideshow` จะลื่นกว่าและไม่พังถ้าเน็ตข้างนอกล่ม
> (ต้องรันด้วย `--lan` ไม่งั้นพอร์ตเปิดเฉพาะบน NAS — หรือใช้ URL ผ่าน reverse proxy ตามปกติ)
> (แขกยังใช้ที่อยู่ https ปกติได้)

## 3. สิ่งที่จะเห็นบนจอ

สไลด์โชว์วนสไลด์ 5 ชนิด สลับกันไปตลอดงาน

| ชนิดสไลด์ | หน้าตา |
|---|---|
| **รูปภาพ** | เต็มจอ ซูมช้า ๆ แบบ Ken Burns มีชื่อคนส่งเป็นป้ายมุมซ้ายล่าง |
| **วิดีโอ** | เต็มจอ เล่นแบบ **ปิดเสียง** จนจบคลิป (สูงสุด 30 วิ) แล้วไปต่อ |
| **คำอวยพร + รูปที่แนบมา** | ใช้รูปที่แขกแนบมาเต็มจอ แล้ววางคำอวยพรทับด้านล่างบนแผ่นไล่เฉดมืด |
| **คำอวยพรล้วน** | ไม่ได้แนบไฟล์ก็ยังขึ้นจอ — จัดเป็นการ์ดข้อความกลางจอ มีลายเส้นทองคั่น |
| **การ์ดชื่อคู่บ่าวสาว** | อักษรย่อ ชื่อ วันที่ สถานที่ ขึ้นเปิดงานและแทรกทุก ๆ 24 สไลด์ |
| **การ์ด QR** | เต็มจอทุก ๆ 12 สไลด์ (ป้าย QR เล็กมุมขวาล่างอยู่ตลอดอยู่แล้ว) |
| **แผ่นจาก photo booth** | แผ่นที่บูธพิมพ์ให้แขก ขึ้นจอเหมือนรูปทั่วไป (เฉพาะงานที่มีบูธ) |

**รูปใหม่มาก่อนเสมอ** — คนที่เพิ่งกดส่งจะได้เห็นรูปตัวเองขึ้นจอทันทีขณะยังถือมือถืออยู่
คำอวยพรก็เช่นกัน และวนเป็นคิว ไม่สุ่ม ทุกคนที่เขียนมาจะได้ขึ้นจอ ไม่ใช่คนเดิมซ้ำ ๆ

### รายละเอียดที่ตั้งใจออกแบบไว้

- **ไม่มีแถบดำข้างภาพ** — รูปจากมือถือส่วนใหญ่เป็นแนวตั้ง วางบนจอ 16:9 แล้วเหลือที่ว่าง
  สองข้าง ระบบเอารูปเดิมมาเบลอขยายเต็มจอเป็นพื้นหลัง จอจึงเต็มโดยไม่ต้อง crop รูปของแขกทิ้ง
- **ตัวอักษรปรับขนาดตามความยาวคำอวยพร** — "ขอให้มีความสุข" ขึ้นตัวใหญ่เต็มจอ
  ส่วนข้อความยาว ๆ จะเล็กลงให้พอดีจอ ไม่ล้นและไม่ต้องเลื่อน
- **เวลาอ่านคิดจากจำนวนตัวอักษร** — คำอวยพรยาวจะค้างจอนานขึ้นเองอัตโนมัติ
- **ขอบจอมืดลงเล็กน้อยและมีเกรนฟิล์มบาง ๆ** — ดึงสายตาเข้ากลางจอ และกลบขอบภาพ
  ของโปรเจกเตอร์ที่มักสว่างไม่เท่ากัน
- **แถบเวลาบางที่ขอบล่าง** — บอกว่าอีกนานแค่ไหนจะเปลี่ยนภาพ โดยไม่แย่งความสนใจ
- **เคอร์เซอร์เมาส์ถูกซ่อน** — ไม่ต้องเข็นเมาส์ไปมุมจอเองก่อนงานเริ่ม

> ถ้าเจ้าภาพซ่อนรูปที่แขกแนบมากับคำอวยพร **คำอวยพรจะยังขึ้นจอต่อ** แค่ไม่มีรูปประกอบ
> ไม่ใช่หายไปทั้งใบ

### แผ่นจาก photo booth บนจอ

งานที่ซื้อทั้งเว็บและบูธ **แผ่นที่บูธพิมพ์ให้แขกจะขึ้นจอด้วยอัตโนมัติ** ไม่ต้องตั้งอะไร
(งานที่ไม่มีบูธไม่มีอะไรเปลี่ยน เพราะไม่มีแผ่นให้ขึ้นอยู่แล้ว)

ขึ้นเป็น **แผ่นที่ประกอบเสร็จแล้ว** ไม่ใช่รูปดิบทีละใบ — แผ่นมีชื่องานกับกรอบของงานนั้น
อยู่ในตัว จึงดูเหมือนของที่ตั้งใจทำ ไม่ใช่รูปหลุดมาปนสามใบติดกัน · และมันคือป้ายโฆษณา
บูธที่ดีที่สุดในงาน: คนเห็นแผ่นสวย ๆ บนจอแล้วเดินมาต่อแถว

ปิดได้ที่ **`/admin` → ตั้งค่า → "แผ่นจากบูธขึ้นจอสไลด์โชว์"** · สวิตช์นี้จะโผล่ก็ต่อเมื่อ
งานนั้นมีแผ่นจากบูธจริงแล้วเท่านั้น (สวิตช์ที่กดแล้วไม่มีอะไรเกิดขึ้นมีแต่ทำให้สับสน)

รอบที่ **หมดอายุ** ไปแล้วจะไม่ขึ้นจอ — ไฟล์ถูกลบไปแล้วเหลือแต่แถวไว้ให้ QR บนกระดาษ
ตอบได้ว่า "รูปหมดอายุแล้ว" เอาขึ้นจอจะได้แค่กรอบว่างที่โหลดไม่ขึ้นค้างอยู่ทั้งงาน

## 4. ปรับจังหวะให้เข้ากับงาน

แก้ใน `.env` แล้ว `sudo docker compose up -d`

```env
SLIDESHOW_SECONDS=8               # วินาทีต่อรูป — งานเลี้ยงคึกคักใช้ 6, งานนิ่ง ๆ ใช้ 10
SLIDESHOW_VIDEO_MAX_SECONDS=30    # ตัดคลิปยาวไม่ให้ค้างจอนานเกิน
SLIDESHOW_MUTED=true              # false = เปิดเสียงวิดีโอ (ไม่แนะนำถ้ามีวงดนตรี)

SLIDESHOW_MESSAGE_EVERY=5         # แทรกคำอวยพรทุกกี่สไลด์ (0 = ไม่แทรก)
SLIDESHOW_QR_EVERY=12             # การ์ด QR เต็มจอทุกกี่สไลด์ (0 = ไม่ต้อง)
SLIDESHOW_TITLE_EVERY=24          # การ์ดชื่อคู่บ่าวสาวทุกกี่สไลด์ (0 = ไม่ต้อง)

SLIDESHOW_MESSAGE_SECONDS=11      # เวลาอ่านขั้นต่ำ ข้อความยาวได้เวลาเพิ่มเอง
SLIDESHOW_KEN_BURNS=true          # false = ภาพนิ่งสนิท ถ้าเครื่องฉายกระตุก
```

ค่าที่ควรปรับจริง ๆ มีสองตัว

| อยากได้แบบไหน | ปรับอะไร |
|---|---|
| เน้นรูป คำอวยพรเป็นของแถม | `SLIDESHOW_MESSAGE_EVERY=8` ขึ้นไป |
| ช่วงพิธี อยากให้คำอวยพรเด่น | `SLIDESHOW_MESSAGE_EVERY=3` |
| เครื่องฉายเก่า ภาพกระตุกตอนซูม | `SLIDESHOW_KEN_BURNS=false` |

### เลือกรูปแบบจากหน้าเมนู

มีหน้าเลือกให้แล้ว ไม่ต้องจำ URL

```
https://wedding.shafiq-lap.com/slideshow/menu
```

- **หน้าแอดมิน** มีปุ่ม "สไลด์โชว์ขึ้นจอ" พาไปหน้านี้
- **แอปบนทีวี** เปิดมาที่หน้านี้เลย เลือกด้วยปุ่มลูกศรบนรีโมตแล้วกด OK
- **กดปุ่มย้อนกลับบนรีโมต** จะกลับมาหน้าเมนูให้เลือกใหม่ กดซ้ำอีกทีถึงจะออกจากแอป

หน้าเมนูส่งค่าที่ติดมากับ URL อย่าง `lite` กับ `lang` ต่อไปให้ด้วย ทีวีที่ตั้งโหมดเบาไว้
จึงไม่หลุดโหมดตอนเลือกจากเมนู

### สองรูปแบบให้เลือก: โรงหนัง หรือ กำแพงรูป

ต่อท้าย URL เพื่อสลับดูสด ๆ ได้เลย ไม่ต้องแก้อะไร

```
https://wedding.shafiq-lap.com/slideshow?mode=cinema    ทีละรูปเต็มจอ (ค่าเริ่มต้น)
https://wedding.shafiq-lap.com/slideshow?mode=wall      กำแพงรูปโพลารอยด์
```

| | **cinema** | **wall** |
|---|---|---|
| หน้าตา | รูปเดียวเต็มจอ เปลี่ยนไปเรื่อย ๆ | รูปสิบกว่าใบกระจายทั้งจอเหมือนวางบนโต๊ะ ทีละใบถูกยกขึ้นมาสว่าง ใบอื่นหรี่ลง |
| รูปของแขก | ผ่านไปแล้วผ่านเลย | ค้างอยู่บนจอได้นาน แขกมีเวลาชี้ให้เพื่อนดู |
| คำอวยพร | ขึ้นเป็นการ์ดข้อความเต็มจอ | ขึ้นเป็นกระดาษโน้ตปนอยู่ในกอง มีช่องกันไว้ให้เสมอ |
| ชื่องาน | การ์ดชื่อเต็มจอทุก 24 สไลด์ | โพลารอยด์ใบหนึ่งวางอยู่บนกำแพงตลอด ย้ายที่ไปเรื่อย ๆ |
| คำอวยพรที่แนบรูป | ข้อความทาบบนรูปเต็มจอ | ข้อความทาบบนรูปใบนั้น โผล่ตอนถูกยกเป็นไฮไลท์ |
| วิดีโอ | เล่นเต็มจอจนจบ | ภาพปกมีไอคอนเล่นที่มุม พอถูกยกเป็นไฮไลท์ก็เล่นจริง |
| เหมาะกับ | ช่วงพิธี อยากให้ทุกคนดูสิ่งเดียวกัน | ช่วงเลี้ยง คนเดินไปมา แวะดูเป็นช่วง ๆ |

**กำแพงรูปทำงานยังไง**

- รูปวางบนตารางแล้วเขย่าตำแหน่งกับหมุนเอียงทีละใบ ได้ผลดูสุ่มแต่ไม่ทับกันจนบังหน้าคน
- กรอบใช้สัดส่วนของรูปจริง แนวตั้งกับแนวนอนจึงหน้าตาไม่เหมือนกัน เหมือนกองรูปจริง
- ไฮไลท์ขยายใหญ่แล้วดึงเข้ามาในจอเท่าที่จำเป็น ใบริมจอจึงไม่โดนตัด
- **รูปใหม่ที่แขกเพิ่งส่งจะเข้าไปแทนใบที่อยู่บนกำแพงมานานที่สุด** โดยข้ามใบที่กำลัง
  เป็นไฮไลท์อยู่ ไม่งั้นรูปจะหายไปต่อหน้าคนที่กำลังดู
- **กำแพงกันช่องไว้ให้คำอวยพรราว 20% ของช่องทั้งหมด** (จอ 16:9 = 3 ใบจาก 15) และทุกรอบ
  ที่ดึงของใหม่ (ทุก 15 วินาที) จะใช้คิวใบแรกกับคำอวยพรที่ยังไม่ได้ขึ้นจอเสมอ
  ถ้ามีรออยู่ — ไม่ว่าคิวรูปจะยาวแค่ไหน ทุกคนที่เขียนมาจึงได้ขึ้นจอแน่นอน
  รูปจะไม่ไปเบียดคำอวยพรออก และคำอวยพรก็หมุนเวียนกันเองเมื่อโควตาเต็มแล้ว
- **วิดีโอเล่นเฉพาะตอนถูกยกเป็นไฮไลท์** ทีละใบเท่านั้น ถ้าเล่นทุกใบพร้อมกันกล่องทีวีตาย
  พอผ่านไปก็หยุดและคืนหน่วยความจำ กลับไปเป็นภาพปกเหมือนเดิม
  ถ้ากล่องถอดรหัสไฟล์นั้นไม่ได้ ก็ค้างที่ภาพปกไว้ ไม่ใช่กลายเป็นกรอบดำ
- **กำแพงมีการ์ดชื่องานเป็นโพลารอยด์ใบหนึ่ง** — โหมดกำแพงถอดเวทีหลักทิ้ง
  การ์ดชื่องานแบบเต็มจอของโหมดโรงหนังจึงไม่มีทางขึ้นเลย คนที่เพิ่งเดินเข้างานมาจะเห็นแต่กองรูป ไม่รู้ว่างานของใคร
  ตอนนี้จึงทำเป็นโพลารอยด์พื้นเข้มใบหนึ่ง มีโมโนแกรม ชื่อบ่าวสาว สถานที่ และวันที่บนขอบกรอบ
- **ของประจำสองใบ (QR + ชื่องาน) วางห่างกันอย่างน้อยสองก้าวเสมอ** ทั้งตอนวางครั้งแรก
  และตอนย้าย ไม่งั้นจะไปกองมุมเดียวกัน เหลือกำแพงอีกฝั่งเป็นรูปแขกล้วน ดูไม่สมดุล
  และทั้งคู่สลับช่องกับการ์ดรูปเท่านั้น สลับกันเองไม่ได้ — ไม่งั้นระยะห่างที่ตั้งใจไว้จะพังทันที
- **QR เป็นการ์ดใบหนึ่งบนกำแพง ไม่ใช่ป้ายมุมจอ** — ป้ายมุมจอทับการ์ดที่อยู่ใต้มัน
  จนอ่านไม่ออก ตอนนี้ QR มีช่องของตัวเอง ย้ายที่ไปเรื่อย ๆ ไม่บังมุมเดิมตลอดงาน
  และมีกฎสองข้อ: **ไม่ถูกยกขึ้นมาเป็นไฮไลท์** (ถ้าขยายจะไปบังรูปแขกรอบ ๆ) และ
  **หลบใบที่กำลังจะขยายอยู่ข้าง ๆ** เพื่อไม่ให้ถูกทับจนสแกนไม่ได้
- QR ไม่หรี่ตามใบอื่น เพราะมีไว้ให้สแกน ต้องอ่านได้ตลอด
- **รูปใหม่ไม่เบียด QR ออก** — มันอยู่ประจำ ต่างจากรูปที่หมุนเวียนกันไป
- การ์ดทุกใบใช้**รูปย่อ 720px** ไม่ใช่รูปเต็ม เพราะมีรูปบนจอพร้อมกันสิบกว่าใบ
- ตำแหน่งที่กันไม่ให้หลุดจอ **คิดจากขนาดกล่องหลังหมุนเอียงแล้ว** ไม่ใช่ขนาดกล่องดิบ
  การ์ดเอียงได้ถึง ±8.5 องศา กล่องที่ครอบใบที่เอียงแล้วจึงสูงกว่าเสมอ ถ้าคิดจากกล่องดิบ
  มุมล่างของใบแถวล่างจะยื่นพ้นจอออกไป วัดจริงได้ 3px ในใบรูปธรรมดา และ 26px ในใบที่สูงกว่า
- ทุกอย่างที่ขยับใช้แค่ `transform` กับ `opacity` การ์ดจอทำได้โดยไม่ต้องคำนวณ layout ใหม่

ตั้งเป็นค่าถาวรได้ใน `.env` ด้วย `SLIDESHOW_MODE=wall` แล้ว `sudo docker compose up -d`

### ถ้าจอกระตุก — ใส่ `?lite=1`

```
https://wedding.shafiq-lap.com/slideshow?lite=1
```

โหมดเบาปิดสามอย่างที่กินแรงเครื่องฉายมากที่สุด เหลือแค่การเฟดข้าม

| ปิดอะไร | ทำไมมันหนัก |
|---|---|
| พื้นหลังเบลอ | เบลอเต็มจอ = GPU คำนวณใหม่ทั้งจอทุกเฟรม |
| เกรนฟิล์ม | `mix-blend-mode` ผสมสีทั้งจอทุกเฟรม |
| ซูมภาพ Ken Burns | ขยับ texture ใหญ่ ๆ ตลอดเวลา |

กล่อง Google TV และ Android TV ราคาประหยัดควรใช้โหมดนี้ตั้งแต่แรก
โน้ตบุ๊กหรือมินิพีซีไม่ต้องใช้

> แอป Google TV ตั้ง `?lite=1` มาให้แล้วโดยค่าเริ่มต้น ถ้าทีวีแรงพอและอยากได้

### รูปที่ส่งขึ้นจอ ไม่ใช่ไฟล์ต้นฉบับ

สไลด์โชว์ขอรูปผ่าน `/display/:id` ซึ่งเป็นสำเนาย่อกว้างสุด 1920px สร้างครั้งแรก
ที่มีคนขอแล้วเก็บไว้ใช้ซ้ำ ต้นฉบับไม่ถูกแตะต้อง (ZIP ตอนท้ายงานยังได้ของเต็ม)

รูปจากมือถือสมัยนี้ 12 ล้านพิกเซลขึ้นไป ถ้าส่งไฟล์เต็มให้กล่องทีวีถอดรหัสทุกสไลด์
จอจะกระตุกและบางครั้งขึ้นดำเพราะหน่วยความจำไม่พอ ปรับขนาดได้ที่ `DISPLAY_SIZE`

กด **ลูกศรขวา** หรือ **Space** บนคีย์บอร์ดเพื่อข้ามสไลด์ด้วยมือ

## 5. ถ้ามีรูปไม่เหมาะขึ้นจอ

เปิด `/admin` บนมือถือของคุณ (ล็อกอินค้างไว้ก่อนงานเริ่ม) แล้วกด **ลบ** หรือ **ซ่อน**
ที่รูปนั้น — จะหายจากจอภายในไม่เกิน 15 วินาที

ถ้าอยากกันไว้ก่อน ให้เปิด **ตรวจสอบก่อนขึ้นแสดง** ในหน้า `/admin`
แต่ต้องมีคนคอยกดอนุมัติตลอดงาน

## 6. ทนต่อปัญหาหน้างาน

หน้าสไลด์โชว์ออกแบบให้ไม่พังง่าย

- เน็ตหลุด → วนรูปที่โหลดไว้แล้วต่อไป ไม่ขึ้นจอขาว
- วิดีโอเสีย/เล่นไม่ได้ → ข้ามไปสไลด์ถัดไปอัตโนมัติ
- วิดีโอที่ยังแปลงไม่เสร็จ → ไม่ถูกนำขึ้นจอ (กันจอดำ)
- ยังไม่มีรูปเลย → ขึ้น QR ใหญ่กลางจอพร้อมข้อความชวนถ่ายรูป
- เปิดค้างนาน → รีเฟรชตัวเองทุก 6 ชั่วโมง

## เชื่อมต่อทีวีโดยไม่ต้องพิมพ์อะไรด้วยรีโมต

การพิมพ์ URL ด้วยปุ่มลูกศรบนรีโมตคือขั้นตอนที่ช้าที่สุดและพิมพ์ผิดบ่อยที่สุด
ของการติดตั้งหน้างาน · ตอนนี้ไม่ต้องพิมพ์แล้ว

1. ตั้งแอปบนทีวี (หรือเบราว์เซอร์ของทีวี) ให้เปิด **`https://<ที่อยู่เว็บ>/tv`**
   ครั้งเดียวตอนติดตั้ง — หลังจากนี้ไม่ต้องแตะที่อยู่อีกเลย
2. ทีวีจะขึ้น **รหัส 6 ตัว + QR** ตัวใหญ่อ่านจากท้ายห้องได้
3. เจ้าภาพ **สแกน QR ด้วยกล้องมือถือ** (แอปกล้องปกติ ไม่ต้องลงแอปสแกน)
   → เข้าหน้าแอดมิน (ล็อกอินถ้ายังไม่ได้ล็อกอิน แล้วระบบพากลับมาที่เดิมให้)
   → เลือกรูปแบบสไลด์โชว์ → กดเชื่อมต่อ
4. **ทีวีเปลี่ยนหน้าเข้าสไลด์โชว์เองภายในไม่กี่วินาที**

สแกนไม่ติด (จอสะท้อน/กล้องมัว) ก็เปิดหน้าแอดมิน → **เชื่อมต่อทีวี** แล้วพิมพ์รหัส
6 ตัวที่เห็นบนจอได้เสมอ · รหัสใช้ตัวอักษรที่ไม่มี I L O U จึงไม่มีทางสับสนกับ 1 กับ 0

### ข้อที่ออกแบบไว้แล้วและควรรู้

- **รหัสบนจอทีวีไม่ใช่กุญแจ** ใครถ่ายรูปจอไว้ก็ทำอะไรไม่ได้ เพราะการยืนยันต้อง
  ผ่านคนที่ล็อกอินแอดมินอยู่แล้วเสมอ · รหัสหมดอายุใน 15 นาที และใช้ได้ครั้งเดียว
- **รีบูตทีวีแล้วไม่ต้องจับคู่ใหม่** ทีวีจำได้เองว่าอยู่งานไหนโหมดไหน — สำคัญมาก
  กับงานสามวันที่มีคนถอดปลั๊กทีวีทุกคืน
- **หลายจอในงานเดียวได้** ตั้งชื่อแยก (โถงหน้า / ในห้อง) และคนละโหมดกันได้
- เปลี่ยนโหมดหรือย้ายทีวีไปอีกงาน: เปิด `/tv?pair=1` บนทีวี หรือกด **เลิกเชื่อมต่อ**
  ในหน้าแอดมิน แล้วจับคู่ใหม่
