# บทที่ 4 · ต่อจอ Slideshow ในงาน

หน้า `/slideshow` ออกแบบมาให้เปิดทิ้งไว้บนจอโปรเจกเตอร์หรือทีวีทั้งงาน
รูปที่แขกเพิ่งอัพโหลดจะ **แทรกขึ้นจอภายในไม่กี่วินาที** ซึ่งเป็นตัวกระตุ้น
ให้คนอื่นอยากส่งรูปตามมากที่สุด

---

## 1. เตรียมเครื่องฉาย

ใช้โน้ตบุ๊กเครื่องไหนก็ได้ต่อ HDMI เข้าทีวี/โปรเจกเตอร์

**ตั้งค่าที่ห้ามลืม**

- ปิด Screen saver และ Sleep (Windows: Settings → Power → Screen and sleep → Never)
- ปิดการแจ้งเตือน (Windows: Focus assist / macOS: Do Not Disturb)
- เสียบสายชาร์จไว้ตลอด
- ปิดการอัปเดตอัตโนมัติในวันงาน

## 1.5 ถ้าใช้ Google TV — มีแอปให้แล้ว

Google TV **ไม่มีเบราว์เซอร์ติดมาให้** และการพิมพ์ที่อยู่ด้วยรีโมตในวันงานคือ
จุดที่พลาดได้ง่ายที่สุด จึงมีแอปเล็ก ๆ ให้ติดตั้ง — เปิดแล้วขึ้นสไลด์โชว์ทันที
ไม่ต้องพิมพ์อะไร ไม่ดับจอ วิดีโอเล่นเอง เน็ตสะดุดก็กลับมาเอง

ขั้นตอนทั้งหมดอยู่ที่ [`tv/README.md`](../tv/README.md)

> แอปคือ WebView ที่ชี้มาหน้า `/slideshow` ตัวเดิม ไม่ได้เขียนสไลด์โชว์ขึ้นใหม่
> แก้หน้าเว็บที่เดียว ทีวีได้ตามทันทีโดยไม่ต้องลง APK ใหม่

**ยังต้องมีแผนสำรอง** — ต่อโน้ตบุ๊กเข้า HDMI แล้วเปิด Chrome เต็มจอตามหัวข้อถัดไป
ซ้อมทั้งสองทางไว้ อย่าพึ่งทางเดียว

## 2. เปิดแบบเต็มจอ

```bash
# Windows
chrome.exe --kiosk --incognito "https://wedding.ali-nurul.synology.me/slideshow"

# macOS
open -a "Google Chrome" --args --kiosk --incognito "https://wedding.ali-nurul.synology.me/slideshow"
```

หรือเปิดเว็บธรรมดาแล้วกด **F11**

> **แนะนำ**: ถ้าเครื่องฉายอยู่ในสถานที่เดียวกับ NAS ให้ชี้ไปที่ IP ใน LAN ตรง ๆ
> เช่น `http://192.168.2.2:18090/slideshow` จะลื่นกว่าและไม่พังถ้าเน็ตข้างนอกล่ม
> (ต้องรันด้วย `--lan` ไม่งั้นพอร์ตเปิดเฉพาะบน NAS — หรือใช้ URL ผ่าน reverse proxy ตามปกติ)
> (แขกยังใช้ที่อยู่ https ปกติได้)

## 3. สิ่งที่จะเห็นบนจอ

สไลด์โชว์วนสไลด์ 5 ชนิด สลับกันไปตลอดงาน

| ชนิดสไลด์ | หน้าตา |
|---|---|
| **รูปภาพ** | เต็มจอ ซูมช้า ๆ แบบ Ken Burns มีชื่อคนส่งเป็นป้ายมุมซ้ายล่าง |
| **วิดีโอ** | เต็มจอ เล่นแบบ **ปิดเสียง** จนจบคลิป (สูงสุด 30 วิ) แล้วไปต่อ |
| **คำอวยพร + รูปที่แนบมา** | ใช้รูปที่แขกแนบมาเต็มจอ แล้ววางคำอวยพรทับด้านล่างบนแผ่นไล่เฉดมืด |
| **คำอวยพรล้วน** | ไม่ได้แนบไฟล์ก็ยังขึ้นจอ — จัดเป็นการ์ดข้อความกลางจอ มีลายเส้นทองคั่น |
| **การ์ดชื่อคู่บ่าวสาว** | อักษรย่อ ชื่อ วันที่ สถานที่ ขึ้นเปิดงานและแทรกทุก ๆ 24 สไลด์ |
| **การ์ด QR** | เต็มจอทุก ๆ 12 สไลด์ (ป้าย QR เล็กมุมขวาล่างอยู่ตลอดอยู่แล้ว) |

**รูปใหม่มาก่อนเสมอ** — คนที่เพิ่งกดส่งจะได้เห็นรูปตัวเองขึ้นจอทันทีขณะยังถือมือถืออยู่
คำอวยพรก็เช่นกัน และวนเป็นคิว ไม่สุ่ม ทุกคนที่เขียนมาจะได้ขึ้นจอ ไม่ใช่คนเดิมซ้ำ ๆ

### รายละเอียดที่ตั้งใจออกแบบไว้

- **ไม่มีแถบดำข้างภาพ** — รูปจากมือถือส่วนใหญ่เป็นแนวตั้ง วางบนจอ 16:9 แล้วเหลือที่ว่าง
  สองข้าง ระบบเอารูปเดิมมาเบลอขยายเต็มจอเป็นพื้นหลัง จอจึงเต็มโดยไม่ต้อง crop รูปของแขกทิ้ง
- **ตัวอักษรปรับขนาดตามความยาวคำอวยพร** — "ขอให้มีความสุข" ขึ้นตัวใหญ่เต็มจอ
  ส่วนข้อความยาว ๆ จะเล็กลงให้พอดีจอ ไม่ล้นและไม่ต้องเลื่อน
- **เวลาอ่านคิดจากจำนวนตัวอักษร** — คำอวยพรยาวจะค้างจอนานขึ้นเองอัตโนมัติ
- **ขอบจอมืดลงเล็กน้อยและมีเกรนฟิล์มบาง ๆ** — ดึงสายตาเข้ากลางจอ และกลบขอบภาพ
  ของโปรเจกเตอร์ที่มักสว่างไม่เท่ากัน
- **แถบเวลาบางที่ขอบล่าง** — บอกว่าอีกนานแค่ไหนจะเปลี่ยนภาพ โดยไม่แย่งความสนใจ
- **เคอร์เซอร์เมาส์ถูกซ่อน** — ไม่ต้องเข็นเมาส์ไปมุมจอเองก่อนงานเริ่ม

> ถ้าเจ้าภาพซ่อนรูปที่แขกแนบมากับคำอวยพร **คำอวยพรจะยังขึ้นจอต่อ** แค่ไม่มีรูปประกอบ
> ไม่ใช่หายไปทั้งใบ

## 4. ปรับจังหวะให้เข้ากับงาน

แก้ใน `.env` แล้ว `sudo docker compose up -d`

```env
SLIDESHOW_SECONDS=8               # วินาทีต่อรูป — งานเลี้ยงคึกคักใช้ 6, งานนิ่ง ๆ ใช้ 10
SLIDESHOW_VIDEO_MAX_SECONDS=30    # ตัดคลิปยาวไม่ให้ค้างจอนานเกิน
SLIDESHOW_MUTED=true              # false = เปิดเสียงวิดีโอ (ไม่แนะนำถ้ามีวงดนตรี)

SLIDESHOW_MESSAGE_EVERY=5         # แทรกคำอวยพรทุกกี่สไลด์ (0 = ไม่แทรก)
SLIDESHOW_QR_EVERY=12             # การ์ด QR เต็มจอทุกกี่สไลด์ (0 = ไม่ต้อง)
SLIDESHOW_TITLE_EVERY=24          # การ์ดชื่อคู่บ่าวสาวทุกกี่สไลด์ (0 = ไม่ต้อง)

SLIDESHOW_MESSAGE_SECONDS=11      # เวลาอ่านขั้นต่ำ ข้อความยาวได้เวลาเพิ่มเอง
SLIDESHOW_KEN_BURNS=true          # false = ภาพนิ่งสนิท ถ้าเครื่องฉายกระตุก
```

ค่าที่ควรปรับจริง ๆ มีสองตัว

| อยากได้แบบไหน | ปรับอะไร |
|---|---|
| เน้นรูป คำอวยพรเป็นของแถม | `SLIDESHOW_MESSAGE_EVERY=8` ขึ้นไป |
| ช่วงพิธี อยากให้คำอวยพรเด่น | `SLIDESHOW_MESSAGE_EVERY=3` |
| เครื่องฉายเก่า ภาพกระตุกตอนซูม | `SLIDESHOW_KEN_BURNS=false` |

### ถ้าจอกระตุก — ใส่ `?lite=1`

```
https://wedding.shafiq-lap.com/slideshow?lite=1
```

โหมดเบาปิดสามอย่างที่กินแรงเครื่องฉายมากที่สุด เหลือแค่การเฟดข้าม

| ปิดอะไร | ทำไมมันหนัก |
|---|---|
| พื้นหลังเบลอ | เบลอเต็มจอ = GPU คำนวณใหม่ทั้งจอทุกเฟรม |
| เกรนฟิล์ม | `mix-blend-mode` ผสมสีทั้งจอทุกเฟรม |
| ซูมภาพ Ken Burns | ขยับ texture ใหญ่ ๆ ตลอดเวลา |

กล่อง Google TV และ Android TV ราคาประหยัดควรใช้โหมดนี้ตั้งแต่แรก
โน้ตบุ๊กหรือมินิพีซีไม่ต้องใช้

> แอป Google TV ตั้ง `?lite=1` มาให้แล้วโดยค่าเริ่มต้น ถ้าทีวีแรงพอและอยากได้
> เอฟเฟกต์ครบ กดปุ่ม MENU บนรีโมตแล้วลบ `?lite=1` ทิ้ง

### รูปที่ส่งขึ้นจอ ไม่ใช่ไฟล์ต้นฉบับ

สไลด์โชว์ขอรูปผ่าน `/display/:id` ซึ่งเป็นสำเนาย่อกว้างสุด 1920px สร้างครั้งแรก
ที่มีคนขอแล้วเก็บไว้ใช้ซ้ำ ต้นฉบับไม่ถูกแตะต้อง (ZIP ตอนท้ายงานยังได้ของเต็ม)

รูปจากมือถือสมัยนี้ 12 ล้านพิกเซลขึ้นไป ถ้าส่งไฟล์เต็มให้กล่องทีวีถอดรหัสทุกสไลด์
จอจะกระตุกและบางครั้งขึ้นดำเพราะหน่วยความจำไม่พอ ปรับขนาดได้ที่ `DISPLAY_SIZE`

กด **ลูกศรขวา** หรือ **Space** บนคีย์บอร์ดเพื่อข้ามสไลด์ด้วยมือ

## 5. ถ้ามีรูปไม่เหมาะขึ้นจอ

เปิด `/admin` บนมือถือของคุณ (ล็อกอินค้างไว้ก่อนงานเริ่ม) แล้วกด **ลบ** หรือ **ซ่อน**
ที่รูปนั้น — จะหายจากจอภายในไม่เกิน 15 วินาที

ถ้าอยากกันไว้ก่อน ให้เปิด **ตรวจสอบก่อนขึ้นแสดง** ในหน้า `/admin`
แต่ต้องมีคนคอยกดอนุมัติตลอดงาน

## 6. ทนต่อปัญหาหน้างาน

หน้าสไลด์โชว์ออกแบบให้ไม่พังง่าย

- เน็ตหลุด → วนรูปที่โหลดไว้แล้วต่อไป ไม่ขึ้นจอขาว
- วิดีโอเสีย/เล่นไม่ได้ → ข้ามไปสไลด์ถัดไปอัตโนมัติ
- วิดีโอที่ยังแปลงไม่เสร็จ → ไม่ถูกนำขึ้นจอ (กันจอดำ)
- ยังไม่มีรูปเลย → ขึ้น QR ใหญ่กลางจอพร้อมข้อความชวนถ่ายรูป
- เปิดค้างนาน → รีเฟรชตัวเองทุก 6 ชั่วโมง
